# Md Adnan Hossen — Developer Portfolio

A modern, responsive personal developer portfolio built with **Next.js 16, TypeScript, Tailwind CSS v4, and React Icons**. This portfolio showcases my skills, projects, education, and interests in software development through a clean and developer-focused design.

## 🚀 Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4 and custom CSS variables
- **Icons:** React Icons
- **Runtime:** Node.js 22

## ✨ Features

- Responsive navigation with a mobile menu
- Hero section with a typewriter effect
- About me section
- Skills organized by category
- Featured project cards
- Education details
- Development focus areas
- Contact information and social links
- Scroll-to-top button
- SEO metadata configuration
- Customizable theme using CSS variables

## ⚙️ Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have the following installed:

- Node.js 22
- npm
- Git (optional)

### Installation

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd portfolio
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the application**

Visit [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

To create a production build:

```bash
npm run build
```

To start the production server:

```bash
npm start
```
